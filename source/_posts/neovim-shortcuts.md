我这套 Neovim 用的是 AstroNvim，`<Leader>` 设成了空格。下文的 `空格 ff` 是依次按空格、`f`、`f`，`Ctrl+z` 则是同时按。表里的键位默认在普通模式下使用。记不清空格后面接什么时，可以按下空格等一下，让 Which-key 显示提示。

## 找文件和切换缓冲区

| 快捷键 | 用途 |
| --- | --- |
| `空格 ff` | 按文件名找文件。 |
| `空格 fw` | 在项目里搜文本，适合找某个函数的调用处。 |
| `空格 fb` | 从已打开的缓冲区里选一个。 |
| `[b` / `]b` | 切到上一个 / 下一个缓冲区。 |
| `空格 e` / `空格 o` | 开关文件树 / 在文件树和编辑区之间切换焦点。 |
| `空格 -` / `空格 fy` | 在 Yazi 中打开当前文件所在目录 / 当前工作目录。 |
| `空格 w` / `空格 c` | 保存文件 / 关闭当前缓冲区。 |

## 编辑和跳转

| 快捷键 | 用途 |
| --- | --- |
| `u` / `Ctrl+r` | 撤销 / 重做。 |
| `/`，再用 `n` / `N` | 在当前文件搜索，跳到下一个 / 上一个匹配。 |
| `v` / `V` | 进入可视模式，按字符 / 按整行选择。 |
| `vaf` | 光标在函数里时，选中整个函数，包括签名和函数体。 |
| `[f` / `]f` | 跳到上一个 / 下一个函数的开头。 |
| `gcc` / `gc` | 切换当前行的注释 / 在可视模式下切换选中行的注释。 |
| `[d` / `]d` | 跳到上一个 / 下一个诊断。 |
| `空格 lf` | 用当前配置的格式化工具整理缓冲区。 |
| `空格 gg` | 打开 Lazygit，查看改动或暂存文件。 |

函数选区和函数跳转依赖当前语言的 Tree-sitter 解析器及其函数查询。

## 在 Neovim 里用 Codex

Sidekick 把 Codex CLI 打开在右侧，面板占 Neovim 总宽度的 40%。 快捷键和面板宽度的设置见 [dotfiles 中的 Sidekick 配置](https://github.com/guangl/dotfiles/blob/b19a74561b5bfb76524853292f5bedcf6fd769e3/home/dot_config/nvim/lua/plugins/sidekick.lua)。

| 在哪里按 | 快捷键 | 用途 |
| --- | --- | --- |
| 编辑区 | `空格 aa` | 打开或收起 Codex 面板。 |
| 编辑区 | `空格 af` | 把当前文件的引用放进 Codex 输入框。 |
| 编辑区 | `空格 aF`（大写 `F`） | 把光标所在函数的源码放进输入框，焦点切到 Codex。 |
| 编辑区，可视模式 | `空格 av` | 把选中的代码放进输入框。 |
| Codex 面板 | `Ctrl+z` | 切回编辑区，右侧面板继续显示。 |
| Codex 面板 | `Ctrl+.` | 收起面板，会话继续运行。用 `空格 aa` 可以再打开。 |

问一个函数时，把光标放在函数里，按 `空格 aF`，然后在输入框补一句「这段代码在输入为空时会返回什么？」最后按 `Enter` 提交。遇到嵌套函数，快捷键会取光标所在的最内层函数。

如果终端没识别 `Ctrl+.`，在 Codex 输入状态下先按 `Ctrl+q` 进入终端缓冲区的普通模式，再按 `q` 收起面板。临时想把面板调到 45 列，可以在按完 `Ctrl+q` 后执行 `:vertical resize 45`。
